# Ψώνια & Αποθήκη

Shopping Companion App v1 — a Greek web app for household shopping: own products, pantry counts, next-order list (use per month, stock, offers), purchases by paste or receipt photo (read on the device), monthly budget.

- Open: https://panosfrantzis.github.io/psonia/
- Data: Supabase (Frankfurt, EU); each household sees only its own data (row-level security). The key in `index.html` is Supabase's publishable browser key.
- Built 2026-10-30 (Claude solo draft for Panos Frantzis).
