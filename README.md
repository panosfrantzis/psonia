# Ψώνια & Αποθήκη

Psonia v2 — Pantry Stock-Up for any household: next order, stock, offers, price change, cheaper swaps, refresh from sklavenitis.gr (console script), monthly spend; plus a shared household (join code) and purchases by paste or receipt photo (read on the device). Same maths and tabs as Pantry Stock-Up.

- Open: https://panosfrantzis.github.io/psonia/
- Data: Supabase (Frankfurt, EU); each household sees only its own data (row-level security). The key in `index.html` is Supabase's publishable browser key.
- Built 2026-10-30 (Claude solo draft for Panos Frantzis).
